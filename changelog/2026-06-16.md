# 2026-06-16

## 需求
发布 v20260616 版本，包含 2026-06-15 的所有功能更新和修复。

## 实现

### 语音识别（ASR）优化
- 修复云端模式（DashScope）实时识别文字不输出的问题（`asr:interim` 事件未注册）
- 修复按空格发送后重复显示已发送内容的问题（位置追踪替代前缀匹配）
- 替换手写 WebSocket 为标准 `ws` 库，解决中文乱码问题
- DashScope 热词表 API 集成，英文专业词汇识别准确率显著提升
- 支持 Fun-ASR、Qwen-ASR、Paraformer 三种云端模型

### 热词管理（新功能）
- AI 自动从简历/岗位信息中提取专业术语
- 6 个内置技术方向预设模板（前端/后端/数据科学/产品/设计/运维）
- 统一热词配置，本地 sherpa-onnx 和云端 DashScope 共享

### 知识库管理（新功能）
- 支持上传简历、岗位 JD、技术文档（txt/pdf/doc/docx）
- AI 回答模块可从知识库选择资料，一次上传多处复用
- 文档类型标签管理（简历/岗位 JD/技术文档/其他）
